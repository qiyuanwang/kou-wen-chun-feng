# 叩问春风｜GitHub Pages / Vercel 发布版

这是已经构建完成的纯静态网站。同一个网址会自动适配电脑、平板和手机，不需要分别维护两套代码。

## 推荐：GitHub Pages

1. 在 GitHub 新建一个 **Public** 仓库，例如 `kou-wen-chun-feng`。
2. 把本文件夹里的**全部内容**上传到仓库根目录，包括隐藏的 `.github` 与 `.nojekyll`。
3. 打开仓库 `Settings → Pages`，将 `Source` 设为 **GitHub Actions**。
4. 等待约 1–10 分钟，在 Actions 里看到绿色勾后即可访问。

默认地址通常是 `https://你的用户名.github.io/kou-wen-chun-feng/`。

## 备用：Vercel

最省事的方式是打开 Vercel Drop，把整个文件夹拖进去；也可以把 GitHub 仓库导入 Vercel 后直接点击 `Deploy`。这是纯静态站点，不需要数据库、环境变量或后端服务。

## 版本说明

- 电脑端：宽幅青绿画卷、双栏问卦、完整卦象与六维解读。
- 手机端：竖向题字、单列信息、44px 以上触控区、刘海安全区、PNG 签图分享。
- 声音：五声音阶空灵音景、风声与三枚铜钱独立落声，全部由浏览器本地合成，不加载外部音频。
- 签文：六十四卦专属底稿、三百余条原创片段与设备端去重账本；同一设备保留最近 4096 首签诗，遇到撞句自动重组。
- 保存与微信：普通浏览器优先调用系统的 PNG 文件分享；微信内置浏览器若拦截文件分享，会显示真实签图，可长按保存或发送给朋友。
- 隐私：问题、冷却时间与去重记录只存于访客浏览器，不上传服务器。
- 内容边界：卦象仅作诗意自省，不构成医疗、法律、财务或其他专业建议。

## 国内访问

GitHub Pages 与 Vercel 默认域名都不保证中国大陆所有网络稳定直连。若部分地区打不开，可把相同文件再部署到腾讯 EdgeOne、香港对象存储或已备案域名，网站代码无需修改。
